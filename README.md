# HTTP Client Project

## Overview

This project demonstrates two implementations of an HTTP client in Python.

The first implementation uses the requests library.

The second implementation builds HTTP communication directly on top of TCP sockets.

## Objectives

- Understand HTTP
- Learn TCP sockets
- Build GET requests
- Build POST requests
- Parse HTTP responses
- Compare abstraction levels
